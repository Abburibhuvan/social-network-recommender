# Social Network Recommender

A Python data science project exploring social network graph structures, data cleaning pipelines, and a **"People You May Know" (PYMK)** mutual friend recommendation algorithm.

---

## 📁 Repository Structure

- `01_social_network_exploration.ipynb`: Loads network data, visualizes user graph relationships, friends lists, and page interactions.
- `02_data_cleaning_preprocessing.ipynb`: Cleans raw JSON data, removes empty records, deduplicates friendships and page IDs, and exports cleaned datasets.
- `03_friend_recommendation_system.ipynb`: Implements a mutual friend recommendation algorithm (People You May Know) based on graph connectivity.
- `data.json` & `data2.json`: Raw input graph datasets.
- `cleaned_codebook.json`: Cleaned and preprocessed output dataset.

---

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone git@github.com:Abburibhuvan/social-network-recommender.git
   cd social-network-recommender
   ```

2. Open the Jupyter notebooks in sequence:
   ```bash
   jupyter notebook
   ```
